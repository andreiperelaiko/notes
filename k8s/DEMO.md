# Сценарий скринкаста (≈ 4–5 минут)

Нужно два окна: терминал (подключён к серверу) и браузер.
Запись экрана на Mac: **⌘ + Shift + 5** → «Записать весь экран» → «Записать».
Остановить: кнопка ⏹ в строке меню. Файл сохранится на рабочий стол.

## Подготовка (до записи)

1. **Терминал 1, туннель к интерфейсу.** Держите его открытым всю запись:
   ```bash
   ssh -N -L 18080:192.168.49.2:30080 myserver
   ```
   `192.168.49.2` — это `minikube ip` на сервере, `30080` — NodePort фронтенда.

2. **Терминал 2, рабочий.** Подключиться и очистить кластер, чтобы на записи всё создавалось с нуля:
   ```bash
   ssh myserver
   cd /root/notes-service
   kubectl delete namespace notes --ignore-not-found
   clear
   ```

## Запись

| # | Что делаем | Команда / действие | Что видно |
|---|---|---|---|
| 1 | Показываем кластер и образы | `minikube status`<br>`eval $(minikube docker-env)`<br>`docker images \| grep notes` | Кластер запущен, образы `notes-backend:1.0.0` и `notes-frontend:1.0.0` собраны в minikube |
| 2 | Показываем манифесты | `ls k8s/` | 6 файлов |
| 3 | **Запуск приложения и зависимостей** | `kubectl apply -f k8s/` | Созданы namespace, configmap, secret, statefulset, job, deployments, services |
| 4 | Ждём запуска | `kubectl get pods -n notes -w` (≈ 20–30 с, затем **Ctrl+C**) | Поды переходят в `Running`, `migrate` → `Completed` |
| 5 | **Вывод всех подов** | `kubectl get pods -n notes -o wide`<br>`kubectl get svc,pvc -n notes` | 4 пода, 3 сервиса, PVC `Bound` |
| 6 | **Масштабирование** | `kubectl scale deployment/backend -n notes --replicas=3` | `deployment.apps/backend scaled` |
| 7 | Проверяем реплики | `kubectl get pods -n notes -l app=backend` | Три пода `backend-…` в `Running` |
| 8 | Адрес интерфейса | `minikube service frontend -n notes --url` | `http://192.168.49.2:30080` (браузер ходит туда через туннель) |
| 9 | **Клики в UI** | В браузере открыть **http://localhost:18080** | Пустой список заметок |
| 9a | Создать | Заголовок «Привет из minikube», текст, кнопка **Добавить** | Появилась карточка, тост «Заметка добавлена» |
| 9b | Изменить | Кликнуть карточку, поправить текст, **Сохранить** | Текст обновился |
| 9c | Удалить | Наведение → корзина → **Отменить** в тосте → снова удалить | Карточка исчезла, вернулась, исчезла |
| 9d | Поиск | Создать вторую заметку, ввести слово в поиск | Фильтр «1 из 2» |
| 10 | Балансировка (бонус) | В терминале:<br>`for i in $(seq 9); do curl -s -D - -o /dev/null http://$(minikube ip):30080/api/notes \| grep -i x-instance; done` | Ответы приходят от разных реплик бэкенда |

## После записи

Ничего удалять не нужно. Если хочется освободить ресурсы сервера:
```bash
minikube stop
```
